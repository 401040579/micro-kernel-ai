# MicroKernel AI - 开发路线图

## Phase 0：体验原型 (PWA on GitHub Pages) — 2周

### 目标
让人用浏览器就能体验"说需求 → 看到应用"的感觉，验证核心假设。

**核心假设**：非技术用户能否通过自然语言成功描述需求并得到满意的结果？

### 交付物
- GitHub Pages 部署的 PWA
- 文字输入需求 → AI理解 → 生成可交互页面预览（不仅是静态HTML）
- AI需求理解与结构化摘要（用户确认后再生成）
- 3个预设Demo场景（记账/待办/客户管理）引导首次使用
- 基础UI组件库（≥15个组件）
- 分享预览链接功能
- 品牌视觉 & Landing Page
- **无需注册即可体验**（先体验价值，再要求登录）

### 技术栈
- Vite + React + TypeScript + Tailwind CSS
- Service Worker (离线缓存)
- manifest.json (PWA安装)
- Claude API (需求理解 + 代码生成)
- iframe沙箱（预览隔离）

### 成功标准
- 首次预览时间 < 30秒
- Demo场景完成率 > 70%
- 收集100+用户反馈

---

## Phase 1：核心引擎 — 6周

### 目标
真正的微内核运行时，能生成可交互的简单应用，形成完整的生成-预览-迭代闭环。

### 里程碑
- [ ] 微内核调度器 v1（插件注册/发现/组合/生命周期管理）
- [ ] 消息总线（插件间通信）
- [ ] 基础插件系统（UI/数据/逻辑三类，≥30个内置插件）
- [ ] AI需求 → 插件匹配 → 组合生成管线
- [ ] 实时预览沙箱（iframe + HMR热更新）
- [ ] 多轮对话上下文管理
- [ ] 增量修改（不重新生成整个应用）
- [ ] 修改历史 & 撤销（最近10次）
- [ ] 数据持久化（本地IndexedDB）
- [ ] 代码安全扫描管线

### 成功标准
- 生成成功率 > 80%
- 平均对话轮次 < 5轮
- 增量修改不破坏已有功能

---

## Phase 2：对话迭代 & 语音 — 4周

### 目标
多轮对话修改应用，热插拔新功能，引入语音输入。

### 里程碑
- [ ] 语音输入集成（Web Speech API + Whisper后备）
- [ ] 语音口语过滤（"嗯""那个"等填充词）
- [ ] 语音快捷命令（"撤销"、"重做"、"部署"）
- [ ] 对话上下文深度优化（跨会话记忆）
- [ ] 预览中点击元素直接修改
- [ ] 模板库（≥20个行业模板）
- [ ] 用户认证系统（注册/登录）
- [ ] 项目管理（列表/创建/删除）

### 成功标准
- 语音识别准确率 > 95%（中文普通话）
- 用户使用语音的比例 > 30%
- 7日留存 > 40%

---

## Phase 3：全平台输出 & 商业化 — 6周

### 目标
一次描述，导出多平台应用。付费系统上线。

### 里程碑
- [ ] Web应用导出（完整React项目）
- [ ] 一键部署到 Vercel / Cloudflare Pages
- [ ] React Native 移动端导出（iOS + Android）
- [ ] Tauri 桌面端导出
- [ ] 后端服务自动生成（Supabase集成）
- [ ] 数据库自动设计
- [ ] 付费系统上线（Free/Pro/Team）
- [ ] 自定义域名支持
- [ ] 导出源代码（Pro功能）

### 成功标准
- MAU > 10,000
- 付费转化率 > 3%
- MRR > $5,000

---

## Phase 4：生态建设 — 持续

### 目标
开放插件市场，社区驱动增长。

### 里程碑
- [ ] 插件开发SDK（@microkernel-ai/sdk）
- [ ] 插件市场上线（社区贡献 + 官方审核）
- [ ] 模板商城（创作者上传 + 分成机制）
- [ ] API开放平台
- [ ] 多人协作编辑
- [ ] 团队版功能
- [ ] 企业版私有部署
- [ ] 国际化（英文版）

### 成功标准
- 社区贡献插件 > 100个
- MAU > 100,000
- MRR > $100,000

---

## 总时间线

```
Month 1       │ Phase 0: PWA体验原型 → 验证核心假设
Month 2-3     │ Phase 1: 核心引擎 → 完整生成迭代闭环
Month 3-4     │ Phase 2: 对话迭代 + 语音 → 差异化体验
Month 4-6     │ Phase 3: 全平台 + 商业化 → 开始赚钱
Month 6+      │ Phase 4: 生态建设 → 构建壁垒
```

## 关键风险检查点

| 时间 | 检查内容 | 止损线 |
|------|---------|--------|
| Month 1末 | 用户能否通过自然语言生成满意的应用？ | Demo完成率 < 30% → 重新审视核心假设 |
| Month 3末 | 用户是否持续使用？ | MAU < 1,000 → 复盘产品方向 |
| Month 6末 | 用户是否愿意付费？ | MRR < $5,000 → 考虑pivot |
